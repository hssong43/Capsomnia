# Caps Lock 한영 전환과 길게 눌러 끄기

## 목표와 범위

Caps Lock으로 한영을 전환하는 환경에서 잠자기 방지가 짧은 키 입력에 꺼지지 않게 한다. 기존 macOS의 길게 눌러 켜기는 유지하고, 켜진 상태에서 끄려면 0.8초 이상 누르도록 한다. 입력 이벤트는 소비하거나 재전송하지 않는다. 메뉴·단축키·타이머의 명시적 종료는 유지한다.

기존 HID 관찰로 실제 누름과 뗌을 읽고, 기존 250ms polling에서 길게 누르기를 확인한다. 짧게 떼면 Caps Lock ON을 복구한다. 상태 변경은 기존 직렬 coordinator를 재사용한다. 누름 길이는 단조 증가 시간을 쓴다. 이 기능에는 macOS 입력 모니터링 권한이 필요하며, 권한/관찰 불가 상태는 진단과 오류 표시에서 구분한다.

## 작업 순서

1. `CapsLockOffHold`의 짧은 입력 보호, 0.8초 경계, 한 누름당 1회, 중복 보고, 취소, OFF에서 시작하는 입력을 단위 테스트로 재현한다. 실패 확인 후 최소 구현한다.
2. `HIDCapsLockMonitor`와 `CapsomniaApp`의 키 이벤트·polling·명시적 종료에 연결한다. release 누락이나 잠자기 복귀 후 오래된 누름 상태를 폐기한다. 보안 입력 상태에서는 짧은 입력 복원으로 대문자 고정이 다시 활성화되지 않게 한다.
   ON 복원 중에도 다음 물리 입력을 계속 추적한다. 지연된 완료를 직접 조절하는 회귀 테스트로 연속 짧은 입력의 ON 보호와 이어지는 긴 입력의 OFF 직렬화를 검증한다.
3. `swift test`, release 앱 빌드, 최종 diff 확인과 독립 검토를 수행한다. 한글 README에 조작 방법과 권한을 적는다.
4. 기존 앱을 작업 폴더에 백업하고 사용자 설치 앱만 교체한다. 로그인 LaunchAgent·사용자 설정·시스템 helper는 유지한다. 실제 실행·권한·진단을 확인한다.
5. 이 브랜치에서 커밋하고 개인 fork에 한국어 PR을 연다. 승인 없이 merge하지 않는다.

## 검증과 한계

- 기준: `swift test` 183개, 2개 skipped, 실패 0.
- 짧은 한영 입력 중 잠자기 방지와 타이머가 유지되고, 길게 누르면 한 번만 꺼져야 한다.
- 물리 키보드·실제 한영 입력·덮개 닫기는 자동 단위 테스트로 증명하지 못한다. 실제 확인 여부를 최종 결과에 따로 적는다.
- 권한을 허용하지 않으면 키 누름 길이를 정확히 측정할 수 없다. 기존 메뉴 종료는 계속 사용할 수 있다.
- 공식 릴리스로 업데이트하면 이 개인 수정이 덮어써질 수 있다.
